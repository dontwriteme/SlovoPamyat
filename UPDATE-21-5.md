# Светоч v0.21.5 — прокручиваемый поиск, быстрые +/− в главе, компактный хотбар

Обновление собрано на базе **v0.21.4**, без изменения схемы базы данных и логики учебных упражнений. Полный проект Android Studio — папка `slovo-pamyat` внутри ZIP.

## 1. Библия: поиск снова прокручивается

Поле поиска по Библии находится **внутри прокручиваемой области**, над каталогом книг. При прокрутке оно уходит вверх вместе с названиями книг. При открытии длинных результатов поиска поле помещается в **заголовок списка результатов**, поэтому оно тоже прокручивается, а не закрепляется на экране. Ранее установленное оформление (лупа, рамка, очистка) сохранено.

Изменение распространяется на основную вкладку «Библия» и каталог книг внутри выбора отрывка. Учтена предварительная загрузка вкладок.

## 2. Добавить из Библии: быстрые +/− рядом со стихами

Путь: **Коллекции → открыть коллекцию → Добавить из Библии → книга → глава (сетка) → стих (сетка) → полный текст главы**. В этом экране около каждого стиха справа появляется:

- `+` — добавить **именно этот стих** в коллекцию, из которой открыли выбор (без перехода в конструктор);
- `−` — удалить ранее добавленный **отдельный стих** из этой коллекции (без удаления истории заучивания).

Состояние кнопки меняется сразу, **без перезагрузки главы и потери позиции прокрутки**. Можно добавить несколько стихов подряд. Нажатие на **текст стиха**, как и прежде, переносит выбранную ссылку в конструктор отрывка; кнопки `+ / −` его не запускают.

Особый случай: если стих **уже входит в длинный сохранённый отрывок**, отображается `✓` вместо повторного `+`. Такой стих нельзя удалить одной кнопкой: это могло бы без предупреждения разорвать непрерывный отрывок и повредить его структуру. Для изменения состава длинного отрывка используют существующее редактирование отрывка. Кнопки относятся к **открытой коллекции**, а не обязательно к активной на главной.

Прежний быстрый `+ / −` в поиске обычной вкладки «Библия» сохранён.

## 3. Хотбар по согласованному изображению

- Один компактный горизонтальный блок без массивной контурной рамки.
- Над заданиями три группы: **Ознакомление → Сборка → Письмо**, с небольшими монохромными иконками и тонкой линией-скобкой.
- Завершённые задания: зелёная закруглённая ячейка **только с белой галочкой**.
- Текущее задание: светлая ячейка с номером и терракотовой контурной рамкой.
- Будущие задания: нейтральная ячейка с номером.
- Общий счётчик `N / M` расположен **справа внутри хотбара**; отдельный счётчик над блоком убран.
- Количество ячеек рассчитывается по существующей модели урока; для длинных отрывков работает горизонтальная прокрутка внутри самого хотбара.
- Обновление состояний работает без пересоздания текста, поля ввода и других элементов урока.

**Никакие другие элементы урока не переделаны.** Старые упражнения, порядок прохождения, режим разработчика и обработчики ввода сохранены.

## Установка и проверка на телефоне

1. Сделай резервную копию проекта и, по возможности, пользовательских данных на устройстве.
2. Распакуй ZIP в отдельную папку и открой папку `slovo-pamyat` в Android Studio.
3. Синхронизируй Gradle, выполни **Build → Rebuild Project** и **Run**.
4. Устанавливай поверх существующей версии **без удаления приложения**, иначе локальная база может быть потеряна.
5. Проверь поиск в обычной «Библии» (каталог, результаты), быстрые `+ / −` в полной главе при открытии из нужной коллекции, переход по тексту стиха в конструктор и хотбар с разной длиной стихов.

Значение `applicationId` осталось `org.biblememory.app`; `versionCode` увеличен до 27, `versionName` — 0.21.5. Схема БД не менялась.
