# Светоч v0.21.5 — отчёт о проверках

- **32 / 32** проверки маршрутов, исходников и ограничений изменений — пройдены. Проверены прокрутка поиска в каталоге/результатах/предзагруженной вкладке, целевая коллекция в `+ / −`, сохранение конструктора диапазона, динамический хотбар и неизменность базы/остальных учебных файлов.
- **20** сценариев модели `LessonHotbarLogic` — пройдены. Модель не менялась, UI отображает её состояния.
- **27** Java-файлов успешно разобраны Java-компилятором на уровне синтаксиса.
- Файловое сравнение с архивом v0.21.4: из существующих файлов проекта изменены **только** `MainActivity.java`, `app/build.gradle`.
- Предусмотрена защита от дублирования стиха, который уже находится в сохранённом длинном диапазоне.
- Схема `LocalStore.java`, `applicationId`, все ресурсы Библии, существующие учебные методы остались неизменными.

**Ограничение:** тесты проверяют логику и целостность исходников, но **не заменяют** реальную сборку APK, UI-проверку на устройстве и проверку обновления на копии существующей базы. Android SDK в окружении недоступен.
