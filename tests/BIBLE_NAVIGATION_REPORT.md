# Исправление навигации Библии

## Причины

1. В коммите `7f1dd56` обработчик активной вкладки «Библия» начал вызывать только
   `animateBibleIcon(...)` с немедленным `return`. Поэтому `goToMainTab(...)`, уже
   умеющий возвращать внутренние экраны к корню, больше не получал этот клик.
   Теперь сначала вызывается существующая навигация, затем перелистывание на
   актуальной панели. В каталоге `goToMainTab` ничего не перестраивает.
2. В версии `a8556cb` до добавления анимации обычный выбор главы уже напрямую
   устанавливал `Screen.CHAPTER`; `PICKER_VERSES` использовался только для вставки
   из коллекций. Поэтому в доступной истории вторая ошибка не вызвана анимацией.
   Добавлен отдельный экран чтения `VERSES`, использующий ту же четырёхколоночную
   сетку, размеры, отступы и данные, что и существующий picker. Чтение не вызывает
   изменение диапазонов коллекции и не использует picker как своё состояние.

## Поведение

Обычное чтение: BOOKS → CHAPTERS → VERSES → CHAPTER.
Back из текста, открытого через номера стихов: VERSES → CHAPTERS → BOOKS.
Оба способа выбора номера главы (сетка/диалог перехода) открывают номера стихов.
При выборе стиха прокрутка выполняется после layout и имеет приоритет над старой
позицией текста главы; подсветка снимается через 1100 мс. Выбор другой главы
сбрасывает только позицию сетки чтения, Back сохраняет её прежнюю прокрутку.
Поиск сохраняет прежний прямой переход в текст и свой возврат к главам.
Код обеих анимированных иконок, индикатор, размеры панели, кэш основных вкладок,
схема/данные БД и логика вставки отрывков не менялись.

## Проверки

Из корня проекта после `source /workspace/toolchains/env.sh`:

```sh
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:assembleDebug :app:compileDebugUnitTestJavaWithJavac
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -PpickerModelOnly -x :app:createSynodalSearchIndex :app:testDebugUnitTest
python3 tests/check_bible_grids.py
"$ANDROID_HOME/build-tools/35.0.0/apksigner" verify app/build/outputs/apk/debug/app-debug.apk
git diff --check
```

APK собран, подпись проверена. Все тестовые классы компилируются.
12 независимых тестов модели/поиска прошли, ошибок/пропусков нет. Проверка
реальных данных 66 книг, включая все 176 стихов Псалма 118, проходит.
`git diff --check` проходит. Файлы `BookNavigationIcon.java` и
`HomeNavigationIcon.java` не изменены.

В `PickerIntegrationTest` добавлены четыре сценария:

- Полный маршрут от Главной через каталог, книгу, главу, все 176 номеров к
  тексту; прокрутка, временная подсветка и обратная цепочка Back.
- Повторный клик из глав, стихов и текста возвращает каталог всех 66 книг;
  повторный клик в самом каталоге сохраняет экземпляр страницы.
- Чтение не меняет активные границы вставки в коллекцию и не сохраняет записи.
- Выбранный стих получает прокрутку даже при старой сохранённой позиции текста.

Существующие тесты книги покрывают перелистывание, отсутствие очереди,
переключения кэшированных вкладок и завершение аниматора. Существующие тесты
picker покрывают независимый маршрут вставки, диапазоны, Back и хранение.

Полный запуск Android-тестов предпринят, но НЕ выполнен: зависимость Robolectric
`nativeruntime-dist-compat:1.0.16` перенаправляется на `gcp.mirrors.maven.org`,
загрузка блокируется HTTP 403. Компиляция не означает прохождение сценариев.
После применения разрешения домена нужно выполнить:

```sh
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:testDebugUnitTest
```

Реальные нажатия, быстрые переключения и визуальные эффекты на устройстве или
эмуляторе в этой среде пока не проверены. Прежние UI-сценарии и новые регрессионные
сценарии требуют выполнения после устранения сетевого ограничения.
