# Проверка выбора отрывков

Из корня проекта, с JDK 17, Android SDK 35 и Gradle 8.9:

```sh
gradle --no-daemon -I tests/validation.init.gradle -PpickerModelOnly -x :app:createSynodalSearchIndex :app:testDebugUnitTest
gradle --no-daemon -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:testDebugUnitTest
gradle --no-daemon -x :app:createSynodalSearchIndex :app:assembleDebug
```

Первый запуск проверяет модель и обход глав без Robolectric. Второй дополнительно запускает Android Activity и SQLite в Robolectric. Init-скрипт добавляет только тестовые зависимости на время запуска, не меняя зависимости приложения. Для сборки используется готовый отслеживаемый `synodal.sidx`, без его перезаписи.

## Фактически выполнено в облачной среде

- Сборка debug APK — успешно; подпись APK проверена.
- `PassageSelectionTest`: 9 тестов, 0 ошибок, 0 пропусков. Проверены первая точка, включение границ, главы, обратный порядок, редактирование обеих границ, совпадение границ, отмена, смена книги, обычный режим, склонения и фактический обход `Bible.collectionPassage` (Матфея 5:3–12 = 10, 5:3–7:29 = 109 стихов; структура глав задана тестовыми данными).
- `git diff --check` — успешно.
- Lint завершился с прежней ошибкой `NewApi` в `res/values/styles.xml:5` (API 27 при minSdk 26), 39 предупреждений. Ошибка существовала до этой задачи; глобальная тема не изменялась.
- Шесть Robolectric-тестов компилировались, но выполнение сценариев заблокировано загрузкой тестового Android SDK: Maven перенаправляет запрос на `gcp.mirrors.maven.org`, прокси отвечает HTTP 403. Это не успешная проверка сценариев. Адрес добавлен в черновик настроек сети; после применения настроек нужен повторный полный запуск.

Проверить полный маршрут каталог → главы → номера → текст; прокрутку к номеру и исчезновение временной подсветки; неизменность позиции после `+ / −`; закрепление панели на маленьком экране и при увеличенном шрифте; системную навигацию и переключение вкладок; короткие главы и последний стих книги; смену коллекций; восстановление после уничтожения процесса; сохранность реальной старой базы и учебного прогресса. Эти проверки не заменяются тестами модели.

## Изменения данных

Миграций и новых таблиц нет. Отрывок использует существующую запись `entries` и связи карточек. `addPickedPassage` оборачивает присоединение/создание записи и синхронизацию карточек в транзакцию, проверяя полноту связей перед фиксацией. Удаление одиночного стиха использует прежний механизм архивирования учебной записи. Модель выделения существует только в памяти/Bundle и не пишет в учебные таблицы.
