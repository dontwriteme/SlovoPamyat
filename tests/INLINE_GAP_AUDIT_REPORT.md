# Аудит пропусков и упражнений

## Причина и масштаб

Письмо использовало разбиение по пробелам: отдельный `-` считался позицией
упражнения, `InlineGapLogic.core("-")` давал пустую строку, а проверка удаляла
пунктуацию. Поэтому пустое поле не влияло на правильность ответа.
Дополнительно открывающие кавычки и скобки выбранного слова не выводились рядом
с полем, а сборка скрывала весь токен вместе с прилегающей пунктуацией.

Проверен неизменённый `app/src/main/assets/synodal.json`: **66 книг, 1189 глав,
31 169 стихов**. До исправления обнаружено **2235 пунктуационных токенов в
1901 стихе**, потенциально создававших фиктивные поля. Это число потенциальных
позиций, а не число воспроизведённых случайных масок на Android.
Полный перечень с каноническими ссылками книг и знаками:
[INLINE_GAP_AFFECTED_VERSES.tsv](INLINE_GAP_AFFECTED_VERSES.tsv).
Примеры: Бытие 1:29, Бытие 7:23, Откровение 22:2. Откровение 22:1–2 входит
в проверку всех соседних стихов.

## Изменения

- `ExerciseTextLogic`: общий лексический контракт для отображаемых токенов
  и нормализованных слов. Нормализация перенесена из `ReviewLogic` без изменения
  правил: NFKC, регистр, е/ё, игнорирование пунктуации. Дефисное слово остаётся
  одним полем/блоком, но его компоненты сравниваются по прежним правилам.
- `InlineGapLogic`: фильтрация позиций без переиндексации исходного текста,
  восстановление старого черновика по исходным позициям, открывающая пунктуация,
  обязательная независимая проверка каждого поля.
- `GapRotationLogic`: новые случайные маски выбираются только среди слов;
  история счётчиков сохраняет прежние индексы.
- `MainActivity`: письмо и ожидаемый ответ используют один список допустимых
  позиций; начало/конец и старые маски очищаются от пунктуационных позиций;
  сборка скрывает только буквенно-цифровые диапазоны.
- `WordOrderLogic` использует общий критерий слова для объединения знаков
  с соседними блоками. `ReviewLogic`, `AcceptedTextLogic`, `TypingDiffLogic`
  продолжают использовать прежние правила проверки, включая Матфея 5:13.

## Совместимость

Исходные индексы, идентификатор фрагмента и сохранённая маска не сдвигаются.
При восстановлении старого черновика удаляются только ответы для пунктуационных
полей; ответы остальных полей остаются при своих словах. После редактирования
поддерживается и компактный формат черновика. Прогресс упражнений, SQLite,
учебные интервалы, библейский текст и формат постоянного прогресса не менялись.

## Воспроизводимая проверка

```
source /workspace/toolchains/env.sh
python3 tests/audit_inline_gaps.py
```

Скрипт компилирует фактические Java-классы приложения и запускает
`tests/inlinegap/InlineGapAudit.java`. Проверены все стихи, все соседние пары
стихов внутри глав, целые главы, пары соседних глав (включая границы книг),
а также синтетические тексты с тире, дефисами, кавычками, скобками, многоточием,
числами, переводами строк и длинными повторяющимися фрагментами.

Результат: **63 536 текстов, 3 382 164 допустимые позиции, 0 нарушений**.
Для каждой позиции проверяется непустой ожидаемый ответ, приём правильного
ответа и отказ для пустого/пунктуационного ответа. Для каждого текста проверяются
маски всех разновидностей упражнений, сохранность пунктуации при скрытии,
отсутствие пунктуационных блоков, восстановление старых черновиков и совпадение
нормализованного ответа. Проверено исключение «негодна / не годна» Матфея 5:13
и отказ при переносе ответа из пустого поля в соседнее.

Gradle: `assembleDebug` успешно; адресные `LessonHotbarLogicTest` (6) и
`AnswerReviewLogicTest` (12) прошли. Общий запуск: 87 тестов, 84 успешны,
3 сбоя в `PickerIntegrationTest` (`nonemptyNoMatchKeepsQueryUntilClear`,
`ordinaryReaderUsesAll176VerseNumbersAndBackStack`,
`clearingVirtualResultsPreservesCatalogScroll`). Те же сбои отмечены до этой
задачи; полный набор не объявляется успешным.
Проверка `check_bible_grids.py`, подпись APK и `git diff --check` прошли.

## Ограничения

Проверка охватывает модель и точность проверки ответов, но не все возможные
случайные комбинации масок. Перебираются все отдельные позиции; несколько
разновидностей масок дополнительно проверяются с фиксированным seed.
Сохранность пунктуации проверяется без учёта пробельного форматирования:
существующий Android WrapLayout раскладывает слова по ширине экрана.
Визуальная проверка полей, удержания слов и восстановление Activity на устройстве
в этой задаче не выполнялись. SQLite не изменялась; автоматический тест обновления
установленного приложения не запускался. Сохранность черновиков проверена
на уровне модели преобразования индексов и ответов.

Перед публикацией получены новые коммиты ветки `work` до `645c000`.
Исправление перенесено поверх них без конфликтов; повторная сборка и те же
18 адресных тестов прошли. Общий результат 87/84 выше относится к запуску
до этого переноса. Чистые классы токенизации и аудит при переносе не изменились.
