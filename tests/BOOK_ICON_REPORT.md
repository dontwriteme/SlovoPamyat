# Иконка «Библия»

Реализация: `BookNavigationIcon.java`, собственный View в существующем слоте 27 × 27 dp.
`Canvas` рисует обложку, корешок и страницы. За 540 мс книга сжимается, слегка
поднимается, раскрывается и перелистывает отдельный изогнутый лист справа налево.
Завершение оставляет открытую книгу. Закрытие занимает 150 мс, повторный лист —
280 мс. Повторные нажатия во время движения не создают очередь; текущее движение
завершается. Один ValueAnimator на значок, Paint и Path переиспользуются.

`MainActivity.java` связывает только значок с существующими переходами. Повторное
нажатие активной «Библии» не вызывает render и не заменяет текущий экран чтения.
Переход на кэшированную вкладку использует прежний кэш. Размеры панели, подписи,
соседние иконки, индикатор и анимация перехода экранов не менялись.
При pause/resume/destroy и отсоединении View аниматор освобождается, значок
принимает состояние своей вкладки. При пересоздании начальное состояние берётся
из фактически выбранного раздела; существующая логика восстановления экранов
не менялась. При системном отключении анимаций конечное состояние ставится сразу.
Новых зависимостей и XML/drawable-ресурсов нет.

## Проверки

Из корня репозитория, после `source /workspace/toolchains/env.sh`:

```sh
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:assembleDebug :app:compileDebugUnitTestJavaWithJavac
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -PpickerModelOnly -x :app:createSynodalSearchIndex :app:testDebugUnitTest
python3 tests/check_bible_grids.py
"$ANDROID_HOME/build-tools/35.0.0/apksigner" verify app/build/outputs/apk/debug/app-debug.apk
git diff --check
```

APK и все тестовые классы компилируются. APK подписан корректно. Проверка данных
66 книг проходит. Тесты модели/поиска: 12, без ошибок и пропусков.

Новый `BookNavigationIconTest.java` содержит 6 сценариев: промежуточные фазы
раскрытия, повторные нажатия, отмена при закрытии, освобождение аниматора,
отключённые системные анимации и переходы с повторным использованием кэша
(Главная ↔ Библия ↔ Коллекции), pause/resume и пересоздание Activity.
`validation.init.gradle` исключает новый Android-класс только в существующем
режиме независимых тестов модели; полный режим включает его.

Выполнение Android-тестов заблокировано сетью: Maven перенаправляет загрузки
Robolectric на запрещённый `gcp.mirrors.maven.org` (HTTP 403). Диагностический
запуск с исключением неиспользуемого native graphics backend также упёрся в
загрузку Android runtime: 12 независимых тестов прошли, 23 Android-теста
завершились ошибкой до выполнения проверок. Это НЕ результаты прохождения
Android-сценариев. Итоговый дополнительный сценарий навигации скомпилирован,
но не выполнен. Для полноценного запуска после применения сетевых настроек:

```sh
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:testDebugUnitTest
```

На устройстве/эмуляторе пока не проверены визуальная выразительность на реальном
размере, пружинность, быстрые переключения, отсутствие смещения соседей,
сохранение движения индикатора, задержка открытия, системное сворачивание,
пересоздание и настройки анимации. Изменения не добавляют задержек/вычислений
перед переключением экрана; это установлено по коду, а не замерами кадров.
Профилирование памяти не выполнялось; отмена и удаление слушателей реализованы
явно, но отсутствие утечек на устройстве не заявляется.
