# Открытая Библия: закладка, листы, крест и свечение

Использовано изображение Библии, приложенное пользователем. Из него подготовлен
прозрачный ресурс `app/src/main/res/drawable-nodpi/bible_open_base.png` без
неподвижных закладки, креста и ореола. Обложка, положение раскрытой книги,
толщина кремовых страниц и их мягкая фактура сохранены в PNG.
В верхней области ресурса нет видимого креста/свечения (alpha не более 1/255).

## Состояния

- Неактивная вкладка: открытая книга, зелёная закладка на правой странице;
  крест и ореол не рисуются, страницы неподвижны.
- Нажатие: закладка вытягивается и исчезает за 210 мс; три отдельных изогнутых
  листа перелистываются справа налево с 140 до 630 мс; крест поднимается с
  580 до 880 мс; мягкий золотистый ореол появляется с 800 мс. Полный цикл 1100 мс.
- Активная вкладка: раскрытая книга без закладки, крест и постоянное мягкое
  свечение; после завершения нет работающего аниматора.
- Повторное нажатие: один лист и небольшое усиление ореола за 380 мс, без
  возврата закладки и повторного подъёма креста. Возврат к каталогу сохранён.
- Выход: ореол гаснет, крест уходит за книгу, закладка возвращается за 190 мс.

Крест и ореол рисуются раньше непрозрачной книги и листов, поэтому поднимаются
именно из-за страниц. Перелистывание — независимые Canvas/Path-листы с изменением
проекции и изгиба, а не поворот целого PNG. Для закладки и креста используются
отдельные градиентные Path. Размер View — прежние 27 × 27 dp.
PNG декодируется один раз с inSampleSize=4; Paint, Path, Shader и RectF
переиспользуются. Один ValueAnimator, без очереди при повторных кликах.

В `MainActivity` добавлена только передача текущего состояния иконки перед
отсоединением исходной страницы: при быстром уходе до появления креста он не
возникает на мгновение в новой панели. Кэш, переходы экранов и обработчики
навигации не переработаны. Главная и её PNG, коллекции, индикатор, поиск,
цепочка BOOKS → CHAPTERS → VERSES → CHAPTER и БД не менялись.
Pause/resume/detach завершают движение в состоянии выбранной вкладки.
При отключённых анимациях конечное состояние устанавливается немедленно.

## Воспроизведение проверок

```sh
# Из корня проекта с JDK 17, SDK 35, Gradle 8.9:
gradle --no-daemon --max-workers=4 -I tests/bible-icon-device.init.gradle -x :app:createSynodalSearchIndex :app:assembleDebug :app:assembleDebugAndroidTest
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:compileDebugUnitTestJavaWithJavac
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -PpickerModelOnly -x :app:createSynodalSearchIndex :app:testDebugUnitTest
python3 tests/check_bible_grids.py
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w org.biblememory.app.test/org.biblememory.app.BibleIconCheck
# На тестовом устройстве с animator_duration_scale=0:
adb shell am instrument -w -e disabled true org.biblememory.app.test/org.biblememory.app.BibleIconCheck
```

APK и instrumentation APK собраны, все тестовые классы компилируются, подпись
APK проверена. 12 независимых тестов модели/поиска прошли без ошибок и пропусков.
Проверка данных всех 66 книг проходит, включая 176 стихов Псалма 118.
`git diff --check` проходит.

`BookNavigationIconTest` обновлён под новую последовательность и неактивное
состояние. Отдельный framework-runner `BibleIconCheck` использует настоящие
нажатия вкладок и снимает нативные кадры исходного состояния, закладки,
листов, подъёма креста, свечения, повтора, ухода и возобновления. Он также
проверяет отсутствие очереди, быстрый уход до появления креста, возврат к
каталогу и реальный маршрут Псалтирь → 118 → 176 → текст.
Фазы фиксируются для детерминированных изображений. Кадры сохраняются в
`/sdcard/Android/data/org.biblememory.app/files/bible-icon-check/`.

На Android API 28 полный framework-прогон завершился PASS: закладка, листы,
подъём креста/ореол, повтор, отсутствие очереди, быстрый уход до появления
креста, возврат к каталогу, Псалом 118 со 176 номерами стихов и обработчики
pause/resume. Отдельный прогон с animator_duration_scale=0 завершился PASS
для активного и неактивного конечных состояний. Скриншоты исходного,
промежуточного и конечного состояний просмотрены: крест изначально отсутствует,
при подъёме перекрывается страницами, после завершения остаётся с мягким ореолом.

Robolectric-проверки компилируются, но их запуск требует разрешения загрузок
с `gcp.mirrors.maven.org`. Полное системное сворачивание и пересоздание Activity
не заявляются выполненными framework-стендом; подготовленные JVM-сценарии
проверяют соответствие иконки фактически выбранной вкладке при пересоздании.
На программном эмуляторе без KVM не делаются выводы об FPS реального телефона.
Профилирование утечек памяти не выполнялось.
