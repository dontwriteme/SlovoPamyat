# «Главная»: иллюстрация пользователя и прежняя анимация

Упрощённая программная отрисовка домика заменена PNG-иллюстрацией,
подготовленной из приложенного пользователем изображения. Новый ресурс:
`app/src/main/res/drawable-nodpi/home_house_illustration.png`.
Сохранены фактура оливковой крыши, деревянный фронтон, каменная труба,
дверь слева, большое окно справа, камни и растения. При подготовке PNG убраны
светлый фон и неподвижный дым, а стёкла затемнены для анимации включения света.
Это подготовленная версия рисунка с прозрачностью, а не его векторная замена.

`HomeNavigationIcon.java` рисует PNG в прежнем слоте 27 × 27 dp. Bitmap один
раз декодируется с inSampleSize=4, без привязки к Activity, и переиспользуется
кэшированными иконками. На каждом кадре PNG не декодируется.

Прежний ValueAnimator и управление состоянием сохранены:

- Полный цикл 1050 мс: лёгкое увеличение, загорание окна, три исчезающих завитка.
- Повторный клик — один завиток и усиление света за 650 мс, без очереди.
- Выход — гашение за 180 мс, остановка дыма.
- Активная вкладка остаётся освещённой; pause/resume не запускает дым заново.
- Масштаб 0,5× поддерживается, системное отключение даёт конечное состояние.

Янтарный свет и усиление яркости накладываются только на четыре отдельных
стекла. Арочная рама и деревянная перекладина остаются частью рисунка.
Координаты дыма совмещены с трубой нового PNG. Объекты маски, Paint, Shader,
RectF и Bitmap переиспользуются; layout и глобальное clipping не менялись.
`MainActivity.java`, навигация Библии, книга, остальные вкладки и БД не менялись.

## Проверки

```sh
# Из корня проекта, с активированными JDK 17, Android SDK 35 и Gradle 8.9:
gradle --no-daemon --max-workers=4 -I tests/home-icon-device.init.gradle -x :app:createSynodalSearchIndex :app:assembleDebug :app:assembleDebugAndroidTest
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -PpickerModelOnly -x :app:createSynodalSearchIndex :app:testDebugUnitTest
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w org.biblememory.app.test/org.biblememory.app.HomeIconCheck
```

APK и instrumentation APK собраны, подпись APK проверена.
12 независимых тестов модели/поиска прошли без ошибок и пропусков.
`git diff --check` проходит. Новый PNG сохранён в репозитории; временные
изображения, APK, настройки SDK и локальные логи в коммит не включаются.

Стенд `HomeIconCheck` использует framework Instrumentation без Robolectric:
нажатия вкладок, кадры окна/дыма, повторные клики, отмена при уходе и обработчики
pause/resume. Фазы аниматора фиксируются для детерминированных скриншотов.
Результаты находятся в `/sdcard/Android/data/org.biblememory.app/files/home-icon-check/`.
На Android API 28 стенд завершился PASS: переходы из Библии и Коллекций,
сохранение аниматора, освещение, кадры дыма, отсутствие очереди при повторных
кликах, отмена при уходе и вызовы обработчиков pause/resume. Новые скриншоты
и увеличенные нативные кадры просмотрены: PNG отображается, свет совмещён с
четырьмя стёклами справа, дым начинается над трубой, после эффекта окно светится.
Первый холодный запуск стенда сообщил Process crashed без Java crash-log;
обычный запуск Activity прошёл, после переустановки актуального instrumentation
APK повторный прогон успешно завершился. Старые кадры не использовались для
подтверждения новой картинки.

FPS и утечки памяти по профайлеру не проверялись. Программный Android-эмулятор
без KVM не даёт достоверных замеров плавности реального телефона.
Пересоздание Activity и полное системное сворачивание не заявляются
проверенными этим instrumentation-стендом. Отдельные Robolectric-сценарии
по-прежнему требуют доступ к `gcp.mirrors.maven.org` для выполнения.
