# «Коллекции»: магическая перестановка книг между полками

В прежнем слоте 27 × 27 dp используется послойная версия приложенного
пользователем шкафчика: кремово-зелёная палитра, две полки, золотые ножки,
четырёхконечная звезда, декоративные полоски и неподвижная веточка.
Графические слои подготовлены по референсу; это не пиксельное разрезание
исходного PNG. Светильника нет. Основной PNG содержит шкафчик и четыре
неподвижные книги. Две верхние книги и зелёная горизонтальная книга снизу
удалены из него вместе с их следами; они рисуются отдельными прозрачными PNG.
Поэтому на освобождающихся местах нет неподвижных копий или прямоугольников фона.

За 1500 мс три книги последовательно выдвигаются (0–250), немного покачиваются
в воздухе (250–400), перемещаются по отдельным кубическим кривым (400–900)
и встают на новые места (900–1250). Левая верхняя книга переходит вниз,
нижняя поднимается на верхнюю полку, вторая верхняя занимает левое место.
Изменение угла на 90° происходит во время полёта. Масштаб сохраняет пропорции;
нижний отсек допускает более высокую лежащую книгу, чтобы сохранить ширину
стопки без большого пустого зазора. Затем звезда увеличивается, светлеет
и даёт мягкий золотистый ореол (1250–1500).

После завершения порядок сохраняется без фоновых анимаций. Повторное нажатие
выполняет следующую перестановку. Быстрый повтор отменяет старый ValueAnimator
и продолжает оставшуюся траекторию из видимой позиции, без очереди и скачка.
Уход с вкладки сбрасывает исходный порядок до отсоединения кэшированной страницы.
Перестроение активного экрана сохраняет текущий декоративный порядок.
Pause/resume/detach завершают движение без повторного запуска.
При отключённых системных анимациях конечное состояние устанавливается сразу.

Объекты Paint, RectF, Shader, Rect, массив порядка наложения и состояния книг
переиспользуются. Bitmaps декодируются и обрезаются по альфа-границам один раз
с inSampleSize=4; статический кэш не хранит Activity. Навигация вызывается
сразу, до начала анимации. Данные коллекций к геометрии книг не подключены.
Оформление панели, размеры, индикатор, переходы, структура кэша, Главная,
Библия, поиск, база и учебный прогресс не переработаны.

- `app/src/main/java/org/biblememory/app/CollectionsBookMotion.java` — независимая геометрия и состояния.

- `tests/CollectionsBookMotionTest.java` — семь независимых проверок геометрии и состояний.

- `tests/collections-icon-device.init.gradle` — подключение стенда без производственных зависимостей.
- `tests/COLLECTIONS_ICON_REPORT.md` — этот отчёт.

## Воспроизведение проверок

Из корня проекта с JDK 17, SDK 35 и Gradle 8.9:

```sh
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -PpickerModelOnly -I tests/collections-icon-device.init.gradle -x :app:createSynodalSearchIndex :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest
gradle --no-daemon --max-workers=4 -I tests/validation.init.gradle -x :app:createSynodalSearchIndex :app:compileDebugUnitTestJavaWithJavac
python3 tests/check_bible_grids.py
"$ANDROID_HOME/build-tools/35.0.0/apksigner" verify app/build/outputs/apk/debug/app-debug.apk
git diff --check
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/androidTest/debug/app-debug-androidTest.apk
adb shell am instrument -w org.biblememory.app.test/org.biblememory.app.CollectionsIconCheck
# Отдельно с animator_duration_scale=0, затем восстановить исходную настройку:
adb shell am instrument -w -e disabled true org.biblememory.app.test/org.biblememory.app.CollectionsIconCheck
```

Сборки APK и instrumentation APK успешны, подпись APK проверена.
**19 JUnit-тестов прошли: 0 ошибок, 0 пропусков** — семь новых, десять выбора
отрывков и два поиска. Геометрический тест проверяет три полных перестановки
с шагом 2 мс: повёрнутые прямоугольники всех трёх книг не пересекаются и не
выходят из слота иконки; конечные книги помещаются на полках, нижняя сохраняет
ширину стопки. Этот тест не является измерением FPS.
Все Android JVM-тесты компилируются. Выполнение Robolectric по-прежнему
блокируется ранее воспроизведённым HTTP 403 с `gcp.mirrors.maven.org` для
`nativeruntime-dist-compat:1.0.16`; успешный запуск Robolectric не заявляется.
Проверка данных всех 66 книг, включая 176 стихов Псалма 118, проходит.

На программном Android API 28 нативный стенд завершился **PASS** с анимациями
и отдельно **PASS** при animator_duration_scale=0. Проверены немедленное
открытие раздела, все фазы, поворот между полками, повтор, 20 быстрых нажатий,
отмена старых аниматоров, выход посреди полёта, сброс кэшированной иконки,
перестроение активной страницы, прежний возврат из detail-состояния к списку
коллекций и вызовы обработчиков pause/resume. Исходная системная настройка
анимаций восстановлена. Экспорт коллекций до и после каждого прогона совпадает.
Проверка detail-состояния задаёт состояние через reflection без создания
реальной коллекции; проверка данных выполнена на пустой базе тестового AVD.
Новая анимация с пользовательской заполненной базой на телефоне не проверялась.

Нативные кадры исходного состояния, извлечения, зависания, полёта, посадки,
звезды, конечного порядка и сброса сохранены в
`/sdcard/Android/data/org.biblememory.app/files/collections-icon-check/`.
Увеличенные кадры и полный экран просмотрены. Полное системное сворачивание,
пересоздание Activity и профилирование памяти/FPS на реальном телефоне этим
прогоном не заявляются. Классы и ресурсы анимаций Главной и Библии не изменены.
`git diff --check` проходит; посторонние компоненты в изменение не включены.
