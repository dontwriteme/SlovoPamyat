# Тестирование изменения интерфейса «Светоч» v0.21.1

## Автоматическая проверка исходников

- **27 инвариантов** целостности и соответствия изменениям: все пять кнопок главного экрана, подписи удалены, пятая кнопка совпадает по реализации с остальными, новые векторные значки, контекстное меню `⋮` доступно в заголовке, нижние кнопки находятся вне `ScrollView`, в т. ч. в подготовленной вкладке «Коллекции», сохранены прежние методы обучения, поиска и контроля памяти.
- Проверка ограничителей Java на основе маскированных строк/комментариев: количество открытых и закрытых скобок осталось тем же относительно исходного файла. Независимый разбор `javac` обнаруживает только отсутствие классов Android SDK (сам SDK в среде отсутствует); ошибок синтаксиса Java не обнаружено в диагностике.
- Запущена сохранённая проверка v0.21.0: **15 кодовых инвариантов**, SQLite-тест миграции 4 коллекций, сохранение одноимённых записей, неизменность учебного прогресса и мягкое удаление.
- **8 Java-тестов** `AcceptedTextLogic` и `LessonCurriculumLogic`: точность письменного ответа, регистр, пунктуация, пропуски, орфография, порядок слов, этапы урока.

## Регрессии, которые должны быть проверены на устройстве

1. В главной панели выбор коллекции открывается нажатием на компактную кнопку с круговыми стрелками.
2. Все пять действий доступны в одном оформлении; нет старой кнопки «Управлять коллекцией» и текстовых пояснений.
3. Создание коллекции доступно нижней кнопкой в разделе «Коллекции», без верхнего плюса.
4. Внутри коллекции при прокрутке списков видны две нижние кнопки добавления; заголовок содержит `⋮`.
5. Пункт «Изменить порядок» доступен при двух и более отрывках, а пункт «Переместить» использует перекрещённые стрелки.
6. Выбор «Сделать активной» находится только в меню `⋮`; активная коллекция корректно меняется на главной.
7. Подготовленная вкладка «Коллекции» и переключение основных вкладок сохраняют закреплённую нижнюю панель.
8. Письменная «Проверка памяти» продолжает старый незавершённый прогон и не меняет расписание повторения.
9. После обновления старые данные и история обучения доступны.

**Ограничение:** Android SDK и среда исполнения телефона в контейнере недоступны. Полной Android-компиляции и инструментального UI-тестирования нет. Архив содержит исходный проект, а не проверенный APK.
