Сравнение черновика `9683baa` с опубликованной ревизией `5baddb9`. Все числа ниже получены в предыдущем аудите.

## Исходные замеры

Изолированная тестовая БД, один и тот же стенд JVM в этой среде, Robolectric API 28 с Native SQLite, JDK 17, одинаковый тест и viewport 411×730. Главная содержит одну запись «Галатам» из 149 стихов. Первое отображение в таблице выполнялось **после готовности Библии**. Замер включает вызов и синхронный layout в JVM, без отрисовки GPU и без настоящих кадров. Одно прохождение на ревизию, кроме множества нажатий в одном уроке. Счётчик считает вызовы `LocalStore.readQuery`. Он не считает SQLite-записи, прямые `rawQuery`, работу других helper или внутренние запросы SQLite. [Сырые значения CSV](evidence/BENCHMARKS.csv)

В Есфирь 8:9 проба прошла доступные варианты от начала этапа до его завершения: 12 фрагментов и 128 нажатий в черновике, 11 и 127 в публикации. Порядок разбивки мог меняться вместе с версией алгоритма и состоянием выбора масок, поэтому объёмы различаются. Путь нажатия в публикации `OnClick → обновление lessonUsedTiles / lessonPicked → renderLessonBuildSelection → запись при завершении фрагмента`. Смена варианта и фрагмента по-прежнему строит соответствующие View, первый расчёт ширины использует измерение текста и подбор размера группы. Наиболее полезные отдельные метрики на Android — время открыть экран, отклик на правильную/ошибочную плитку, окончание фрагмента, поворот с набранным префиксом, p95 кадров и аллокации. Целевые FPS, задержки конкретных телефонов и выигрыши в процентах из этих данных не следуют. ## Что измерено и чего пока не хватает

| Область | Доказательство и пределы |
| --- | --- |
| Генерация упражнений | Есть время открытия сборки с layout и время подготовки режима памяти. Отдельное время токенизации, выбора масок и генерации плиток не выделялось. |
| Длинные отрывки | Есть проход Есфирь 8:9 и подготовка режима памяти для 149 стихов. Время проверки длинного письменного ответа, полный урок по главе и коллекции 500+ на Android не измерялись. |
| Главный поток | Зафиксированы синхронные чтения прогресса главы и общий монитор загрузки Библии. Длительность блокировки UI и кадры измерить ещё предстоит. [A04](AUDIT.md#a04) · [A05](AUDIT.md#a05) · [A11](AUDIT.md#a11) |
| Перерисовки | По коду обычное нажатие на плитку обновляет выбор локально. Смена фрагмента создаёт View, а общий `render` перестраивает корень. Трассировки redraw и пропусков кадров нет. [A14](AUDIT.md#a14) · [A17](AUDIT.md#a17) |
| Память | Пейзаж 1200×750 при RGBA занимает около 3,4 МиБ по расчёту. Пики PSS и heap, суммарная память bitmap и верхняя граница для бэкапа не измерялись. [A09](AUDIT.md#a09) · [A17](AUDIT.md#a17) |
| SQLite | В таблице есть подмножество чтений через `readQuery`. EXPLAIN подтвердил полный проход по таблице сроков и отдельную сортировку. Время конкуренции между helper не измерялось. [A10](AUDIT.md#a10) · [A12](AUDIT.md#a12) |
| Жизненный цикл и утечки | Код фоновой загрузки удерживает Activity до окончания работы и допускает поздний callback. Постоянная утечка, объём удерживаемой памяти и частота не установлены. [A04](AUDIT.md#a04) |
| Холодный запуск | Время до первого кадра и до готовности Библии не измерялось. Замер главной начинался после загрузки Библии. [A04](AUDIT.md#a04) |
