## Что требует внимания

Исходный аудит выявил 2 проблемы P1, 12 проблем P2 и 4 проблемы P3. Обе P1 исправлены в ветке R2. A01 касалась восстановления копии, A02 — записи попытки. Для резервных копий остаются открытыми A09 (память) и A13 (поддержка исторического JSON). [Реестр](AUDIT.md)

Для старых записей без признака удаления доступность сохраняется. Отдельные вопросы совместимости исторических JSON-копий и памяти при больших архивах описаны в отчётах R2. [Границы R3](DECISIONS.md#d03) · [Совместимость](DECISIONS.md#d05)

## Как поддерживать документы

После каждого согласованного этапа добавляйте запись в [PROGRESS.md](PROGRESS.md) с затронутыми ID, коммитом, результатами и ограничениями. Меняйте статус в [AUDIT.md](AUDIT.md) по конкретному доказательству. Новые замеры и проверки добавляйте в соответствующий отчёт с ревизией и условиями прогона. Согласованные решения фиксируйте в [DECISIONS.md](DECISIONS.md), а изменение порядка работ — в [ROADMAP.md](ROADMAP.md). При новом выводе сохраняйте связь с исходным ID.
