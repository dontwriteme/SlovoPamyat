## 24 ноября 2026 г. · R5.2 · первая проверка выявила потерю прогресса

- A07: исходная R5.1 уже проверяла строки при создании своего текста, но редактирование оставалось отдельным путём без лексической проверки. Новая ветка `refactor/r5-2-custom-text-validation` основана на `ebf803ff6197869fbbfc62de067647a1c94d0af2`.
- `CustomStudyText` использует действующий токенизатор; создание и редактирование получают одинаковую проверку. Ошибка редактирования оставляет диалог открытым. Для ранее сохранённой строки без слов учебный экран предлагает исправить текст вручную, не засчитывая упражнение. Карточка без слов остаётся доступной как карточка, но не создаёт невозможный учебный урок.
- При исправлении без изменения числа строк сохраняются их координаты. При вставке/удалении сопоставляются только однозначно неизменённые тексты. Для неоднозначно перемещённых повторов сохранение прежней идентичности не гарантируется. Удалённые и изменённые строки обрабатываются прежним механизмом `reviseStudyPassage`; автоматических изменений пользовательской БД нет.
- Штатные адресные тесты прошли (23 из 23). Полный JVM-прогон (195 из 195) и сборка APK прошли. Дополнительный тест выявил потерю прогресса неизменённой строки при её смещении в тексте той же длины. [Причина и воспроизведение](TESTING.md#r5-2-review)
