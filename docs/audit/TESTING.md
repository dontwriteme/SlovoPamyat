Для этой строки совпадение отсутствует, и её прогресс удаляется при пересохранении. **SQLite и границы тестов.** В исходном стеке SIGSEGV участвовали `Finalizer → SQLiteConnection.finalize → ShadowNativeSQLiteConnection.nativeFinalizeStatement → sqlite3_finalize`. Интеграционные тесты ожидают завершения обоих executor перед сбросом Robolectric. Отдельная регрессия удерживает работу при уничтожении Activity, проверяет открытое соединение во время работы, его закрытие после выхода и отсутствие поздней перерисовки. Конфигурация режимов NATIVE/LEGACY сохранена, постоянная изоляция JVM и автоматические повторы не вводились.

## Выполненные проверки и известные ошибки

Для опубликованной версии:

- **Gradle 8.9, JDK 17, SDK 35.** `:app:assembleDebug` собрал APK, его подпись v2 прошла `apksigner verify --verbose`. Общая задача `assembleDebug + testDebugUnitTest + lintDebug` завершилась с ошибками тестов и Lint.
- **Полная JVM-регрессия.** При обычном запуске 130 начатых тестов, 4 ошибки, 1 пропуск в неполном результате перед SIGSEGV. Диагностический повтор с теми же тестами и отдельной JVM на класс: **135 тестов, 131 прошёл, 4 упали, 0 пропущено**. Все ошибки в `PickerIntegrationTest`: `nonemptyNoMatchKeepsQueryUntilClear` и `clearingVirtualResultsPreservesCatalogScroll` (нет EditText), `ordinaryReaderUsesAll176VerseNumbersAndBackStack` (нет ожидаемой прокрутки), `overlapDuplicateAndDeletedCollection` (SQLITE_BUSY на удалении). Миграции (2), полный бэкап (2), долговечность прогресса (3), жизненный цикл сессий (9), снимок прогресса (8), орфография (8) и тесты хотбара/упражнений (15 интеграционных) прошли. Пять отдельных диагностических проб выполнены на каждой ревизии, ещё одна проба отказа SQLite выполнена на публикации. Часть проб собирает метрики и состоявшиеся эффекты, поэтому их зелёный статус не означает отсутствия дефектов. [Результаты из XML](evidence/TEST_RESULTS.csv)
- **Android API 28.** На чистом изолированном эмуляторе установлен APK и отдельный тестовый APK. Штатный `BibleIconCheck` вывел PASS: анимация и повторное нажатие, быстрый уход с вкладки, открытие текста после выбора стиха 176 и возврат к каталогу, пауза/возврат Activity. Этот runner проверяет открытие текста, но не величину прокрутки на стих и не ввод в поиск. Четыре ошибки JVM остаются в реестре. Реальные FPS, Android API 26 и принудительное уничтожение процесса после восстановления не проверены. [Вывод прогона](evidence/ANDROID_API28.txt)
- **Статический анализ.** Lint обнаружил 1 ошибку `NewApi` и 47 предупреждений. Крупные группы: 13 `DrawAllocation`, 10 `IconLauncherShape`, 8 `ClickableViewAccessibility`, 4 `UnusedResources`. Граф построен по той же ревизии APK. Процент покрытия строк и ветвей не измерялся.
- **Данные Библии.** Сетки всех 66 книг прошли (`check_bible_grids.py`), включая Псалтирь 118 из 176 стихов. Аудит пропусков прошёл для 66 книг, 1 189 глав, 31 169 стихов, 63 536 текстовых комбинаций и 3 382 164 допустимых позиций. 1 901 стих с 2 235 отдельными знаками — показатели прежнего алгоритма, не текущие ошибки. Орфографический аудит прошёл для 61 149 текстов и отклонил 61 149 лексических подмен, плюс 700 проверок устойчивости разбора. Поисковый индекс пересоздан в отдельном снимке: 31 169 стихов, 33 055 терминов, SHA-256 исходного JSON и индекса совпали с исходными.
- **Черновик для сравнения.** 105 тестов, 102 прошли, 3 ошибки в тех же сценариях поиска и прокрутки. APK собрался. Lint показал ту же ошибку API 26. Отсутствие SQLITE_BUSY в этом прогоне не показывает частоту ошибки.

## Сценарии для расширения регрессии

| Уровень | Проверки, которые следует добавить до соответствующих изменений |
| --- | --- |
| Unit | Общий контракт проверки урока и памяти для точного, частичного, пустого, длинного ввода. Идентичность одинакового текста из разных книг. Детерминированные маски, дубли плиток и смена ширины. Очередь одного стиха в нескольких коллекциях. |
| SQLite-интеграция | Ошибка на каждой операции записи неуспешной попытки, конкурентные чтение и удаление коллекции, повторы с архивом, миграция и восстановление старых файлов, неизменность базы и черновика при ошибке. |
| Android UI | Три сценария Picker, поиск без совпадений и очистка, Псалтирь 118 со скроллом, восстановление урока после системного завершения, фрагменты Есфирь 8:9 в разных размерах и с крупным шрифтом, быстрый выход с фоновой задачей. |
| Производительность | Первая готовность UI на телефоне и смена вкладок, глава 176 стихов и коллекции 1/149/500+, большие ответы, изоляция SQLite при одновременных операциях, пик памяти бэкапа. Собирать времена операций, запросы, аллокации и кадры отдельно. |

## Воспроизведение исходных проверок

Команды для отдельной копии выбранной ревизии с настроенными Gradle 8.9, JDK 17 и SDK 35. `audit_dir` указывает на абсолютный путь к каталогу `docs/audit` с этим отчётом. Тестовые SQLite-данные создаются Robolectric. Внешние диагностические тесты прикрепляются через init-скрипт, без изменений исходных файлов приложения. [Исходник проб](evidence/repro/AuditProbe.java) · [Init для проб](evidence/repro/probes.init.gradle) · [Init раздельного прогона](evidence/repro/isolate.init.gradle)

```bash
gradle --daemon --max-workers=4 --continue -I tests/validation.init.gradle \
  -x :app:createSynodalSearchIndex :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
gradle --daemon --max-workers=4 -I tests/validation.init.gradle \
  -I "$audit_dir/evidence/repro/isolate.init.gradle" -x :app:createSynodalSearchIndex :app:testDebugUnitTest
gradle --daemon --max-workers=4 -I tests/validation.init.gradle \
  -I "$audit_dir/evidence/repro/probes.init.gradle" -PauditProbeDir="$audit_dir/evidence/repro" \
  -x :app:createSynodalSearchIndex :app:testDebugUnitTest --tests '*AuditProbe*'
python3 tests/check_bible_grids.py
python3 tests/audit_inline_gaps.py
python3 tests/audit_orthography.py
```

Тест `failedReviewPartiallyCommitsOnSqliteError` характеризует дефект публикации A02. Остальные пять тестов формируют базовые данные на обеих ревизиях. Аудит пропусков обновляет отчёт TSV, а генератор поискового индекса пишет бинарный файл, поэтому оба запускались на отдельном снимке.
