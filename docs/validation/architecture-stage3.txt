INSTALLED APK UPGRADE
1. Keep/install the pre-extraction APK. The runner checks that study() is absent.
2. Build/install only the new test APK with tests/installed-upgrade-device.init.gradle.
3. adb shell am instrument -w -e phase seed org.biblememory.app.test/org.biblememory.app.InstalledUpgradeCheck
4. Install the new application APK using pm install -r (same package/signature; preserve data).
5. adb shell am instrument -w -e phase verify org.biblememory.app.test/org.biblememory.app.InstalledUpgradeCheck
The seed refuses to overwrite an existing fixture. Verification requires the same pre-existing file, path, v8 schema, all table rows/IDs/order, and no mutation on read. Fixture is private and isolated from the default installed application database. A fresh empty DB is not accepted as an upgrade test.
