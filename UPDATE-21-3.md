# Светоч v0.21.3 — выбор стиха, поиск и прогресс урока

Это полный исходный проект Android Studio, подготовленный **поверх v0.21.2**. Для установки не нужно запускать Python-скрипты или вручную менять Java-файлы.

## Изменения

1. **Настройки коллекции.** У четырёх строк («Переименовать», «Настроить порядок стихов», «Очистить коллекцию», «Удалить коллекцию») удалены стрелки справа. Команды, цвета и подтверждения сохранены.
2. **Меню `⋮` стиха и карточки.** Удалена команда «Переместить». Остались «Изменить отрывок», «Добавить стих / отрывок после него», «Удалить». Изменение порядка учебных элементов выполняется из настроек коллекции.
3. **Поиск по Библии.** Поле оформлено в стиле поиска по коллекциям: контрастная рамка, лупа, крупный однострочный ввод, очистка `×`. Для запуска поиска — лупа или действие поиска на клавиатуре. Поиск по-прежнему выполняется локально.
4. **Полноэкранный урок.** Вместо общей полоски отображаются три одинаковых сегмента — «Ознакомление», «Сборка», «Письмо». Завершённые этапы обозначены зелёным, текущий отображает долю выполненного. Сегмент ознакомления обновляется при изменении степени скрытия; сегмент сборки — по завершённым заданиям и при заполнении слов. Заполнение анимируется без пересоздания упражнения.
5. **Добавление из Библии.** Новая последовательность: **каталог книг (как в «Библии») → сетка глав (существующий дизайн) → сетка стихов → полный текст главы**. При нажатии номера стиха открывается полный текст, нужный стих подсвечивается и автоматически прокручивается в видимую область. **Только после нажатия самого стиха в тексте** он становится выбранной границей и открывается конструктор. Здесь можно сразу добавить один стих либо выбрать конечный стих через такой же маршрут и добавить диапазон, в том числе через несколько глав. Также сохранён ручной конструктор из четырёх полей.
6. **Предыдущие возможности сохранены.** Учебная система, карточки, письменная проверка, режим разработчика, центровка групп книг и существующие данные коллекций не менялись.

## Установка

1. Для надёжности сохрани резервную копию пользовательских данных приложения на телефоне.
2. Распакуй ZIP в папку на компьютере, например `C:\Android\Svetoch\`.
3. Открой папку `slovo-pamyat` в Android Studio через **File → Open**.
4. Выполни Gradle Sync и **Build → Rebuild Project**.
5. Запусти приложение поверх установленной версии. **Не удаляй предыдущее приложение и не очищай его данные.**

## Проверка на телефоне

- Открой существующую коллекцию и убедись, что стрелок справа от четырёх настроек нет, а действия работают по-прежнему.
- Открой меню `⋮` отрывка: команды «Переместить» нет. Удаление и добавление после выбранного элемента доступны.
- Открой вкладку «Библия»: поле поиска выглядит как в «Коллекциях», ввод находит нужные стихи, `×` очищает поиск.
- В коллекции нажми **«Добавить из Библии»**. Должен открыться каталог всех 66 книг с десятью заголовками групп. Выбери **Матфея → 5 → 16**. Должен открыться **полный текст главы** с выделенным стихом 16, а не сразу конструктор.
- Прокрути главу и коснись стиха 16. Должен открыться конструктор с началом и концом **Матфея 5:16**. Добавь стих и убедись, что он появился в коллекции.
- Для диапазона снова начни добавление: выбери Матфея 5:3, нажми «Выбрать конец в Библии», выбери **глава 6 → стих 4**, открой текст и коснись стиха. Подтверди диапазон Матфея 5:3–6:4. Если выбрать стих раньше начала, приложение должно отклонить такую конечную границу.
- Начни занятие. При нажатии «Скрыть 25%» сегмент ознакомления должен измениться. В сборке заполняй блоки: текущий сегмент должен плавно увеличиваться, без скачка расположения слов.
- Проверь, что обычная вкладка «Библия» продолжает открывать текст главы сразу после нажатия на номер главы, а последнее прочитанное место не сбрасывается при добавлении материала в коллекцию.

## Совместимость и ограничения проверки

`applicationId=org.biblememory.app` сохранён, `versionCode=25`, `versionName=0.21.3`. SQL-схема и исходник `LocalStore.java` не менялись, миграции базы нет.

Проверено: 33 статических инварианта UI/навигации/сохранения данных, 8 Java-тестов диапазонов, 8 Java-тестов учебной логики и синтаксический разбор всех 26 Java-файлов. **Полноценная Gradle-сборка Android и визуальное тестирование на устройстве не выполнялись:** в среде нет Android SDK и эмулятора.
