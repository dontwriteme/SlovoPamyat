# Светоч · «Начала стихов» и «Переходы между стихами»

**Тип поставки: ZIP-пакет точечного обновления**, а не архив полностью заменяемого проекта. Так сохраняются последние ручные правки, сделанные непосредственно в Android Studio: кэш вкладок, дизайн стиха дня, перенесённые кнопки «Начать», поиск Библии и удаление недавних отрывков. Исходного полного актуального проекта телефона у поставки нет.

## Установка

1. Сделайте резервную копию рабочего проекта в Android Studio.
2. Распакуйте ZIP. Скопируйте `apply_update.py` и папку `app/src/main/java/org/biblememory/app/` из архива в корневую папку вашего проекта, **не заменяя MainActivity.java вручную**.
3. Откройте терминал Android Studio в корне проекта (`C:\bible_app\slovo-pamyat`, если это ваша текущая папка), и выполните `python apply_update.py`. В Windows при необходимости используйте `py apply_update.py`.
4. Скрипт сначала проверит имеющиеся методы, создаст резервную копию `MainActivity.before_sequence_update.java.bak`, затем добавит только два вызова и три вспомогательных метода в `MainActivity.java`. Он также положит `SequenceRecallLogic.java` и `SequenceRecallController.java` в правильный пакет.
5. Соберите `Build > Rebuild Project` и запустите на телефоне. APK не входит в ZIP.

**Внимание:** если скрипт сообщает, что нужный метод не найден, он не меняет файлы. Не пытайтесь заменить `MainActivity.java` из более старого архива — это удалит ваши недавние изменения. Сообщите точный текст ошибки.

## Механика

- Стихи проходят прежние три стадии: ознакомление → сборка → письмо по памяти. Готовые связки имеют приоритет.
- После освоения непрерывной части из **3 стихов** впервые появляется упражнение «Переходы между стихами» (виден конец предыдущего, вписывается начало следующего).
- После **6** освоенных стихов — «Начала стихов» по номерам, затем «Переходы».
- После **9, 12, 15...** стихов — новые начала и переходы. В новые короткие тренировки повторно входят ранее ошибочные начала.
- После освоения всего непрерывного отрывка длиной от 10 стихов — итоговая проверка обеих способностей. Для больших отрывков поля разбиты на логические окна до 10 стихов.
- Неизученные стихи, пользовательские тексты и несвязанные ссылки из разных книг не попадают в эти упражнения.
- В строке начала используются первые 2–8 слов (расширяются, когда начала слишком похожи). Регистром и пунктуацией можно пренебречь; буквы слов проверяются строго.
- При ошибке показывается правильный вариант; «Повторить ошибки» очищает только неверные ответы. Нажатие «Продолжить» после правильного выполнения возвращает в прежнюю очередь обучения.
- Текущие ответы, слабые начала и результаты новых заданий сохраняются **отдельно в SharedPreferences**. Прогресс ранее изученных стихов, существующие коллекции и интервальное повторение не переписываются.
- Выход системной кнопкой «Назад» в середине нового задания ведёт на главную, а при следующем открытии той же записи задание восстанавливается.

## Ограничения и совместимость

- Android Java + Views, без Kotlin/Compose или новых зависимостей.
- Новый код не изменяет `LocalStore.java` и схему SQLite. `applicationId` остаётся прежним.
- Пакет применим к `MainActivity.java`, содержащему методы `renderFullscreenLesson` и `advanceAfterSuccess` из согласованной версии v0.20.1–v0.20.2. Если пользователь существенно переименовал методы, скрипт остановится безопасно.
- При включении нового упражнения в учебную очередь используется успех полного письменного прохождения (`exerciseDone >= 5`) или существующий статус освоения. Результаты этих дополнительных проверок не влияют на статус уже выученного стиха.
- **Полная Android SDK-сборка и тестирование на реальном устройстве в этой среде недоступны.** Логика проверена обычными Java-тестами. Приложение может потребовать корректировку после запуска в Android Studio.
