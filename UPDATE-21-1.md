# Светоч v0.21.1 — упрощённый интерфейс коллекций

Это **полный проект Android Studio** на основе пользовательской версии «Светоч» v0.21.0.
Содержит все файлы исходного проекта, приложение и встроенную Библию. Python-патчи не требуются.

## Установка

1. Перед обновлением рекомендуется сохранить резервную копию данных на устройстве.
2. Распаковать ZIP в путь без кириллицы, например `C:\Android\Svetoch\`.
3. В Android Studio открыть папку `slovo-pamyat`.
4. Выполнить **Sync Project with Gradle Files**, затем **Build → Rebuild Project**.
5. Установить приложение **поверх существующего**; не удалять установленное приложение, не очищать данные.

`applicationId` сохранён (`org.biblememory.app`). Номер сборки увеличен с 22 до 23, версия с 0.21.0 до 0.21.1. Схема и данные SQLite не изменялись.

## Что изменено

1. **Главная — выбор коллекции:** компактный переключатель в одну строку с подписью, названием и значком из двух изогнутых круговых стрелок вместо галочки/шеврона. При нажатии открывается прежний список выбора коллекций.
2. **Главная — режимы:** убраны все второстепенные пояснения под названиями режимов. Остались одинаковые по оформлению пять строк: «Учить стихи наизусть», «Режим карточек», «Повторение стихов», «Проверка памяти», «Повторить все коллекции».
3. **Иконки:** для «Повторение стихов» добавлен нарисованный значок мозга, для «Проверка памяти» — блокнот с карандашом, для «Повторить все коллекции» — двойные стрелки.
4. **Главная:** удалена кнопка «Управлять коллекцией».
5. **Список коллекций:** удалён дублирующий заголовок «Коллекции» и плюс в верхнем правом углу. Кнопка «＋ Добавить коллекцию» закреплена в нижней области над основной навигацией.
6. **Внутри коллекции:** «Добавить из Библии» и «Добавить свой текст» закреплены в нижней области над основной навигацией. Убраны отдельные кнопки «Сделать активной», «Настройки коллекции», «Изменить порядок отрывков». Все три действия доступны в меню `⋮` в заголовке коллекции (пункт изменения порядка показывается при наличии двух и более отрывков).
7. **Переместить:** в контекстных меню и строках перетаскивания используется значок перекрещённых стрелок.
8. Подправлена область `androidResources.noCompress` в Gradle: она находится непосредственно в `android {}`, а не внутри `defaultConfig {}`.

## Что НЕ менялось

- Коллекции, порядок элементов, их идентификаторы и SQLite-таблицы.
- Результаты изучения стихов и расписание повторений.
- Механики карточек, проверки текста, письменного прогона, поиска и режима разработчика.
- Интерфейс «Библия», цвета книг, уроки и экран успеха.

## Проверка на устройстве

- Выберите коллекцию с главной: значок обновления и весь переключатель вызывают выбор.
- Запустите каждый из пяти режимов: поведение прежнее, кроме нового названия «Проверка памяти».
- Откройте «Коллекции»: заголовка и плюса сверху нет, снизу закреплена кнопка создания.
- Откройте коллекцию: меню `⋮` содержит «Сделать активной» / «Переименовать» / «Удалить»; при 2+ отрывках — «Изменить порядок отрывков».
- Кнопки добавления из Библии и собственного текста остаются видимыми внизу при прокрутке списка.
- Убедитесь, что меню отдельного отрывка содержит новый значок рядом с «Переместить».
- Проверьте сохранение старого прогресса и работу возврата из урока.

## Ограничения проверки

В среде подготовки **нет Android SDK**, поэтому итоговый APK и визуальную работу на физическом телефоне здесь проверить не удалось. Проведены статические проверки вызовов/маршрутов, проверка синтаксического разбора `javac` (без Android classpath), Java-тесты независимой логики и контроль состава архива. Полную сборку необходимо выполнить в Android Studio.
